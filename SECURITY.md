# Security

Wanderlust is experimental software, not a sandbox. Generated executables run with the host process's privileges. Executable parsing, guest memory, service dispatch and graphics-driver interactions are security-sensitive boundaries under active development.

For a vulnerability report, use the repository's private vulnerability-reporting facility when available. Otherwise contact the maintainer through their published contact channels before disclosing sensitive details in a public issue.

Include the affected revision, host platform, a minimal synthetic reproduction and the expected versus observed behavior. Do not include credentials, console keys, commercial executables, game assets, memory dumps or private extraction logs. A small original fixture is preferable to private input data.

No supported security-release series or production security guarantees are currently declared.
